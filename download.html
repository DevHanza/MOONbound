How to install

Four steps. Update your graphics driver first for the best results.

  1. Step 01

    Download the zip

    Click Download for Windows. MEGA opens in a new tab; click its Download button and save the .zip file.

  2. Step 02

    Extract the zip

    Right-click the downloaded file, choose Extract All…, then Extract.

  3. Step 03

    Install the runtime

    In package1.0 › windows, run Engine/Extras/Redist/en-us/vc_redist.x64.exe once. It installs the Visual C++ runtime the app needs.

  4. Step 04

    Run MOONbound

    In the same folder, double-click NASA_Moon.exe. If Windows Firewall asks, allow internet access: the Moon’s terrain is streamed online.

Good to know

  • If Windows shows “Windows protected your PC”, click More info, then Run anyway. It appears because the app isn’t code-signed.
  • Keep the whole windows folder together. Don’t move NASA_Moon.exe out on its own.
  • Stay online while using it. The lunar terrain is streamed, so a slow connection means a blurry surface.

Troubleshooting

The app won’t start or says a DLL is missing

Run vc_redist.x64.exe (step 3).

“DirectX 12 is not supported”

Your graphics card or driver is below the minimum. Update the driver, or use a supported card.

The Moon’s surface is missing or blurry

Check your internet connection. The terrain is streamed online.

Low frame rate

Lower the display resolution, and make sure the dedicated graphics card is in use, not integrated graphics.
